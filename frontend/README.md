# Frontend

This directory houses the Learning Ladder UI experiments. Each project is a standalone Vite + React app.

## Projects

- `chatbot-interface/` – Conversational tutor experience for the Learning Ladder chatbot.
- `homepage-concept/` – Marketing site concept highlighting program features.

## Getting Started

Install dependencies and run a project from the repository root using workspaces (see the top-level README):

```bash
pnpm install
pnpm dev --filter chatbot-interface
```

Alternatively, install and run an individual project directly:

```bash
cd frontend/chatbot-interface
npm install
npm run dev
```

Repeat with `homepage-concept` to explore the second design.
